隱私權政策 (Privacy Policy)

最後修訂日期：2026 年 10 月 31 日 適用版本：SubTrack 1.0 以上 開發者：LU TSE-HSIEN
隱私核心原則：您的財務紀錄 100% 留在您的 iPhone 本機。
SubTrack 不設有任何自有伺服器，不建立使用者帳號，不嵌入廣告或行為追蹤 SDK，絕不將您的訂閱消費內容上傳至任何雲端資料庫。

1. App 處理與儲存之資料

當您在 SubTrack 中記錄訂閱或固定開銷時，您輸入的資料包含：

  • 訂閱項目名稱、扣款週期（週、月、季、年）、扣款金額、幣別標籤
  • 扣款起始日、首次扣款日、試用期截止日期與續約週期錨點
  • 自訂或預設分類標籤、付款來源備註（僅作為標籤分類，不輸入也不儲存金融卡號或銀行帳密）
  • 停用、暫停、取消續訂或封存之狀態註記

上述資料全部使用 Apple 原生 SwiftData 技術加密儲存於您的 iOS 裝置本機沙盒空間中。App 預算目標、外觀深淺色偏好及本地通知開關則保存在系統偏好設定（UserDefaults）中。

【重要保證】：SubTrack 沒有任何銀行帳戶連線功能、不需註冊或登入帳號、無任何分析追蹤程式碼（Analytics），開發者無法且永遠不會接收、調閱或販售您的任何訂閱清單與金額。

2. Apple 購買驗證與本地通知

2.1 Apple In-App Purchase (StoreKit 2)

當您在 App 內購買或升級為 SubTrack Pro 時，所有的訂單處理、信用卡扣款、帳單開立、續約與退款均由 Apple App Store 官方金流系統直接處理。

開發者不接收亦不保留您的信用卡號、帳單地址或 Apple ID 帳號密碼。SubTrack 僅透過 Apple 官方 StoreKit 2 介面接收經 Apple 數位簽署的安全收據，於本機驗證購買狀態以解鎖進階功能。

2.2 本地通知 (Local Notifications)

若您啟用了扣款或試用期到期提醒，SubTrack 會利用 iOS 系統的本地排程通知功能（UNUserNotificationCenter）於裝置上建立提醒。該提醒完全在您手機本機排程觸發，不需要任何遠端推播伺服器參與。若您拒絕授予通知權限，僅提醒功能暫停，完全不影響任何訂閱記錄與統計之運作。

3. 使用者主動匯出與外部連結

3.1 CSV 檔案匯出

SubTrack 支援將您的訂閱資料匯出為 CSV 試算表格式。匯出行為完全由您主動觸發，並透過 iOS 系統原生分享面板（Share Sheet）儲存至本機檔案或傳送給您指定的接收者。

3.2 官方訂閱管理網址

App 目錄中可能提供主流訂閱服務（如串流平台、軟體服務）之官方帳號管理快速連結。點擊該連結將使用系統瀏覽器開啟該服務的官方網站，其後續所有互動皆受該第三方網站之隱私政策管轄。

4. 資料保存、備份與刪除權益

  • 手動刪除：您可隨時在 App 內單筆滑動刪除或清空項目。
  • 移除 App：若您將 SubTrack 從 iPhone 上刪除，iOS 系統會依其安全機制一併清除沙盒內所有儲存之訂閱資料。
  • 系統備份：您的資料會隨同 iOS 系統的整機備份（如 iCloud 整機備份或電腦本機 iTunes/Finder 備份）一同保存，此備份加密狀態受您的 Apple ID 與個人 iCloud 隱私條款保護。

5. 支援網站之伺服器記錄說明

本支援網站由 GitHub Pages 託管，頁面純為靜態 HTML，無任何第三方廣告或訪客追蹤 Cookie。依據 GitHub 官方政策，GitHub Pages 伺服器會在安全與維運合規範圍內暫時記錄連線請求的 IP 位址，詳情請參考 GitHub Pages 說明 與 GitHub 隱私權聲明。
